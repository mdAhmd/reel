Add your Reels

Open this HTML file in a text editor and find const REELS. Add one object for each Reel:

const REELS = [
  {
    url: "https://www.instagram.com/reel/SHORTCODE/",
    title: "A good one"
  },
  {
    url: "https://www.instagram.com/reel/ANOTHER_CODE/",
    title: "Another Reel"
  }
];
  1. Copy the Reel's normal Instagram link and paste it between the quotes.
  2. Duplicate an object to add more Reels. Keep commas between objects.
  3. Save the file and publish the updated HTML to your hosting service.

Use public Reels from accounts that allow embedding. Instagram decides how its player looks and behaves; this page cannot remove Instagram's own controls or login prompts.
